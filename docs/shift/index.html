ColourShift

Make one colour look different.

Choose a target colour and a starting surround, then explore alternative surrounds predicted to change its hue and chroma most strongly.

Chrome blocks this app when opened as a file. Start a local server, then open http://localhost:8000/.

Your comparisons will appear here.

About this experiment

ColourShift is a model-driven exploration, not a guarantee that every observer, display, or lighting environment will see the same magnitude of change. The browser calculation uses ColourShift’s corrected empirical CIECAM02 white-point proxy: the chosen surround acts as the local reference field, with explicit viewing-condition parameters. It is a studio-search heuristic, not a calibrated observer model.
